# Release Promo Agent

Ежедневный агент: находит самый большой релиз ZenCreator (новая модель или фича) в Slack `#releases`
и Asana, генерирует spicy-футаж в **ZenCreator** и собирает **motion-промо** через скилл
**[bang-motion](https://github.com/bangtutorial/bang-motion)** — два ролика, **9:16 и 16:9**, ~20 с (≤ 30 с).
Готовые ролики приходят в Slack на ревью.

| Что | Где |
|---|---|
| Плейбук агента (читается автоматически в каждой сессии) | `CLAUDE.md` |
| Настройки: каналы, проекты, бюджет, модели, spicy-уровень, куда слать | `config/promo-agent.yaml` |
| Motion-скилл (MIT, копия на коммите из `UPSTREAM_COMMIT`) | `.claude/skills/bang-motion/` |
| Основа ролика: один HTML → два формата, без WebGL | `templates/promo-shell.html` |
| Рендер кадров/MP4 (Playwright + ffmpeg, GSAP из `node_modules`) | `tools/render.mjs` |
| Скачать и подготовить клип ZenCreator | `tools/fetch_clip.sh` |
| Проверка ролика + контактный лист | `tools/qc.sh` |

## Как это работает

1. **Поиск** — сообщения бота «Released to prod» в `#releases` за 26 ч + завершённые задачи Asana; задачи одного эпика склеиваются.
2. **Выбор** — скоринг: новая модель +10, пользовательская фича +6, пресеты/темплейты +5; багфиксы, BE-only, админка — минус. Порог 6.
3. **Без повторов** — агент ищет свои прошлые посты `[release-promo]` в канале доставки: не делает тот же релиз дважды и меняет стиль.
4. **Генерация** — ZenCreator: spicy-кадры (если релиз — модель картинок, кадры делает именно она), затем `videogen` (Seedance 2.0 Fast, 720p, 5 с) — по 2 клипа на формат. Бюджет ≤ 120 кредитов в день.
5. **Motion** — bang-motion: style brief, концепт из меню, анти-PPT законы; рендер обоих форматов, проверка кадров глазами, экспорт MP4, QC.
6. **Доставка** — два MP4 + хук, подпись для поста, style-строка и расход кредитов в Slack.

## Запуск вручную

В сессии Claude Code на этом репозитории: «Запусти промо-агента за сегодня» (или за конкретный релиз: «сделай промо по DEV-5589»).

Для облачных сессий нужен environment **promo-agent (evlampi9a/1)** — в нём открыты `storage.zencreator.pro` (скачивание клипов)
и `files.slack.com` (загрузка роликов). Нужны коннекторы Slack, Asana и ZenCreator.

## Ограничения

- В облаке нет GPU → в роликах нет WebGL/Three.js; фоны на CSS/SVG.
- Экспорт ~3 кадра/с: ролик 20 с ≈ 3–4 мин на формат.
- `spicy_level: spicy_sfw` по умолчанию — соблазнительно, но без обнажёнки, чтобы ролики можно было крутить в соцсетях. `explicit` включается в конфиге.
