# Ежедневный отчёт по экспериментам

1. Прочитай `config/agents.json`.
2. Выгрузи флаги:
   `python3 scripts/unleash_prod_flags.py --out state/flags_today.json --diff state/flags_snapshot.json`
   Возьми те, у которых `is_experiment: true`. Если их нет — так и напиши в отчёте и закончи.
3. Параллельно (одним сообщением):
   - `flag-context-researcher` по экспериментам, пачками по 8 — нужны цель, целевые метрики,
     владелец, плановая дата окончания;
   - после его ответов (или сразу, если контекст не нужен) — `experiment-metrics-analyst`
     пачками по 4 эксперимента, передай флаги + найденный контекст + секцию `amplitude`.
4. Запиши `reports/experiments-YYYY-MM-DD.md` и отправь в `slack.report_channel` (если задан)
   сообщение в формате:

   ```
   🧪 Эксперименты на проде — DD.MM (N запущено)
   Изменения со вчера: +новые / −выключенные / раскатка изменилась
   
   *<flag>* · владелец · день X/Y · <Amplitude|ссылка> · <Asana|задача>
     Конверсия в оплату: control 11.2% → treatment 11.9% (+6.3%, p=0.03)
     Guardrail: …
     ⚠️ SRM / guardrail_drop / ✅ ready_to_decide
   …
   Без трекинга в Amplitude: flag_a, flag_b
   ```

   Сначала эксперименты с сигналами, потом остальные. Не выдавай разницу за результат,
   если значимость не посчитана — так и пиши.
