# Аудит прод-флагов Unleash

1. Прочитай `config/agents.json`.
2. Выгрузи флаги:
   `python3 scripts/unleash_prod_flags.py --out state/flags_today.json --diff state/flags_snapshot.json`
   Если нет `UNLEASH_URL` / `UNLEASH_TOKEN` — остановись и скажи, что их нужно добавить в
   секреты окружения.
3. Разбей флаги на пачки по 8 и запусти параллельно субагентов `flag-context-researcher`
   (одним сообщением, все вызовы Agent сразу). Каждому передай его пачку флагов (JSON) и
   секции `asana` и `slack` из конфига.
4. Собери ответы и запиши `reports/flags-audit-YYYY-MM-DD.md`:
   - Сводка: всего флагов, экспериментов, кандидатов на удаление, флагов без контекста.
   - Изменения со вчера (`diff` из выгрузки): новые / выключенные / изменили раскатку.
   - ⚠️ Противоречия (`concerns`).
   - 🧹 Кандидаты на удаление (флаг, почему, владелец).
   - 🧪 Активные эксперименты (флаг, варианты, владелец, задача в Asana).
   - Таблица всех флагов: флаг | тип | раскатка | владелец | статус | Asana | Slack.
5. Если задан `slack.report_channel` и запуск плановый (или пользователь попросил отправить) —
   отправь краткую версию (сводка + противоречия + кандидаты, до ~40 строк) в канал через
   `slack_send_message`. Иначе просто покажи отчёт.
