Что это значит для редизайна

  1. Промо-баннер вариаций почти не кликают: 0,5% пользователей за неделю. Его можно заменить переключателем количества вариаций без заметного риска для выручки.
  2. Reuse Settings — вторая по охвату кнопка после скачивания (11,1%). Её стоит держать на виду рядом со «Скачать».
  3. Variations, Send to Tool, Edit и Retry используют в 2–4 раза чаще, чем Create Video и Upscale. Порядок кнопок стоит строить по этим цифрам.
  4. Фотошуты из просмотрщика почти не создают (2,0% всех фотошутов). Если это цель, нужна отдельная кнопка вроде «Фотошут с этим лицом».
  5. Ошибку скачивания за месяц видел каждый шестой пользователь просмотрщика. Это стоит разобрать отдельно.
